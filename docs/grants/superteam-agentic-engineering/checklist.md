# Submission Checklist (Antibop)

## Before you submit
- Confirm the grant type + what it covers (tool subscription vs. cash vs. credits).
- Decide the exact ask: Claude Pro / Cursor / ChatGPT Plus / API credits (amount + duration).
- Make sure the repo matches your claims (README + scripts run without errors).

## “Proof of work” links
- GitHub profile
- 2–3 shipped projects (links that load fast)
- Any demos, writeups, or threads

## Demo assets (recommended)
- 60–120s screen recording:
  - Run `npm run test-infra`
  - Run `npm run monitor`
  - Show logs streaming for 10–20 seconds
  - End with a slide/README section showing the 4-week roadmap
- Optional: a short Loom-style voiceover explaining the problem + why it’s agentic

## Application copy (paste-ready)
- Use `grant-application.md` as your long-form answer.
- Use `docs/grants/superteam-agentic-engineering/short-answers.md` for character-limited fields.

## Final verification
- Run `npm run build`
- Run `npm run dev` (should print module status)
